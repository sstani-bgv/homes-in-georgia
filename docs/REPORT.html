Homes in Georgia · платформа

Отчёт по переносу на 2 ноября

Девять репозиториев PlatformDGE, бот-подборщик, CRM, Google Sheets и Apps Script собраны в одну систему: Python + PostgreSQL на бэкенде, React-CRM на дизайн-системе агентства, общий бот. Всё проверено локально на реальной PostgreSQL. Ниже что сделано, что нужно от заказчика и что осталось на следующий этап.

57тестов бэкенда 91тест бота (e2e через фейковый Telegram) 31лист Sheets в импорте 0ключей в коде, всё в .env

Что нужно от заказчика

Срочно

Отозвать токен бота генератора постов

Токен 8724734832:… лежит открытым текстом в публичных репозиториях. @BotFather → /revoke, новый токен положить только в .env.

Срочно

Закрыть старые доступы к таблицам

После переноса данных архивировать все деплойменты Apps Script (сейчас это открытый API к таблицам без авторизации), убрать доступ «по ссылке» у Google-таблицы, сменить пароль старой админки grishashvili.

Нужно

Настоящая выгрузка Google Sheets

В архиве были тестовые строки, поэтому в демо-аналитике есть мусор вроде средней цены $5. С реальным CSV импорт запускается одной командой.

Нужно

Тексты договоров

Старая CRM собирала договоры из шаблонов Google Docs на их Drive, в коде текстов не было. Поля, расчёты и 9 вариантов (аренда, коммерция, продажа × RU/GE/EN) готовы, но текст пунктов написан нами. Его надо заменить юридическим текстом заказчика в одном файле: frontend/src/features/contracts/templates.ts.

Нужно

Telegram: токен, ID чатов и топиков

BOT_TOKEN, рабочая группа операторов, канал объявлений, канал сделок, топики. Бот должен быть админом группы, иначе не видит сообщения в топиках.

Нужно

Хэштеги агентов

Кто есть кто: «#GioCH» → конкретный агент. Заполняется в настройках CRM, нужно для разбора постов и сделок из канала.

Нужно

Ответы Давида по journey

8 открытых вопросов по пути клиента сейчас закрыты разумными значениями по умолчанию, их стоит подтвердить.

Нужно

Сервер

Машина с Docker и доменом для PUBLIC_URL (нужен HTTPS для мини-аппа Telegram).

Не сделано, следующий этап

  • Ручное добавление показа в календаре (сейчас показы берутся только из заявок).
  • Хранение готовых договоров на сервере (сейчас печать в PDF и скачивание .doc).
  • Топ-10 репостов из Telegram: нужна отдельная MTProto-сессия.
  • Номера удостоверений и даты рождения в сделках.
  • Instagram: нужен доступ Meta (App Review), Facebook-группы пока через Apify. Livo и Korter подключены, см. docs/SOURCES.md.

Не проверено

  • Бот с настоящим токеном в настоящей рабочей группе.
  • Запуск через docker-compose: на моей машине нет Docker, сам файл собран и описан.
  • Импорт на реальных данных из Sheets.

Запуск на сервере

cp .env.example .env    # BOT_TOKEN, SECRET_KEY, POSTGRES_PASSWORD, OPERATORS_CHAT_ID, PUBLIC_URL…
docker compose -f deploy/docker-compose.yml --env-file .env up -d --build
docker compose -f deploy/docker-compose.yml exec api sh -c \
  "cd backend && python -m app.importers.sheets_csv /path/to/sheets-csv"
