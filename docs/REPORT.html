Homes in Georgia · платформа

Отчёт на 3 ноября

Девять репозиториев PlatformDGE, бот-подборщик, CRM, Google Sheets и Apps Script собраны в одну систему: Python + PostgreSQL на бэкенде, React-CRM на дизайн-системе агентства, общий бот. Добавлены источники Livo и Korter, по Facebook и Instagram проведено исследование. Ниже: что готово, что проверено и как, что пока не проверено и что нужно от заказчика.

58тестов бэкенда 97тестов бота 31лист Sheets в импорте 0ключей в коде, всё в .env

Что проверено и как

Автотесты

Бэкенд 58, бот 97 (весь путь клиента, оператора и агента через фейковый Telegram), фронтенд собирается без ошибок типов.

Установка из архива

Архив развёрнут на пустую базу: миграции, импорт CSV, API, worker. Все 15 разделов CRM открываются без ошибок.

Живой Telegram, тестовый бот

/start, анкета из 6 вопросов, выбор районов, профиль, меню команд и описание бота работают.

Livo и Korter вживую

Сборщики на реальных сайтах: 96 и 80 объявлений. Конвейер до CRM: ingest → база → лента «Новые объявления» с фото и меткой источника → «Беру в работу» создаёт объект.

Не проверено

  • Подборка квартир в боте и всё после неё: карточки, ❤️, заявка в группу операторов, кнопки оператора и агента вживую. Без ключа нейронки поиск не работает; путь проверен только автотестами.
  • Разбор объявлений нейронкой для Livo и Korter: в проверке конвейера модель была подменена.
  • Запуск через docker-compose на сервере: на машине разработчика нет Docker, доступа к Dokploy нет.
  • Мини-апп и вход в CRM через Telegram: проверятся после выкладки на домен.
  • Импорт настоящих данных из Google Sheets: в архиве были только тестовые строки.

Не сделано

  • Сборщик Instagram: ждёт доступа Meta.
  • Ручное добавление показа в календаре.
  • Хранение готовых договоров на сервере.
  • Топ-10 репостов из Telegram (нужна MTProto-сессия).
  • Номера удостоверений и даты рождения в сделках.

Сервер и домен

Боевой бот

@HomesinGeorgia_bot, токен лежит в env Dokploy. Один токен нельзя запускать в двух местах: прототип надо остановить, когда поднимется новая система.

Telegram-настройки агентства

Из старой CRM, Apps Script и генератора постов: рабочая группа и топик новостей, топики сделок, Make Foto и объявлений, чат и топики публикации, Telegram ID суперадминов, хэштеги ~30 агентов. Готовый блок для env собран. Номера топиков сделок, фото и объявлений нужно подтвердить: ID чата в выгрузке Apps Script был замаскирован.

Аккаунты сотрудников

В выгрузке Sheets только тестовые строки (DEMO_…), настоящих логинов нет. Это не мешает: суперадмины входят через Telegram по ID из env и заводят сотрудников в CRM (Управление → Пользователи), агенты подключаются в боте.

Что нужно от заказчика

Срочно

Отозвать утёкший токен бота

Токен 8724734832:… генератора постов лежит открытым текстом в публичных репозиториях: @BotFather → /revoke. Архивировать деплойменты Apps Script, убрать у таблицы доступ «по ссылке».

Для запуска

Ключ нейронки

OPENAI_API_KEY (подойдёт ProxyAPI с OPENAI_BASE_URL). Без него подборка квартир и разбор новых объявлений не работают.

Для запуска

Выкладка на Dokploy

Сервер, домен и бот уже есть. Нужен доступ к Dokploy либо выкладка силами Стаса: приложение из deploy/docker-compose.yml, env дополнить строками из готового блока, не затирая токен. В @BotFather для @HomesinGeorgia_bot: /setprivacy → Disable, /setdomain → домен. Бот должен быть админом рабочей группы.

Для запуска

Группа операторов

Куда приходят заявки клиентов: отдельная группа или топик в рабочей. Её ID в OPERATORS_CHAT_ID, топик в OPERATORS_TOPIC_ID.

Нужно

Настоящая выгрузка Sheets и тексты договоров

CSV с реальными данными (импорт одной командой) и юридические тексты договоров из их Google Docs: сейчас текст пунктов написан нами, он лежит в frontend/src/features/contracts/templates.ts.

Нужно

Хэштеги агентов и ответы Давида по journey

Кто есть кто по хэштегам (#GioCH → агент), заполняется в настройках CRM. 8 открытых вопросов по пути клиента сейчас закрыты значениями по умолчанию.

Для Instagram

Доступ Meta

Instagram агентства в режиме Business, привязанный к странице Facebook, приложение в Meta for Developers и одобрение доступа Instagram Public Content Access.

Запуск на сервере

cp .env.example .env    # BOT_TOKEN, SECRET_KEY, POSTGRES_PASSWORD, OPERATORS_CHAT_ID, PUBLIC_URL, OPENAI_API_KEY…
docker compose -f deploy/docker-compose.yml --env-file .env up -d --build
docker compose -f deploy/docker-compose.yml exec api sh -c \
  "cd backend && python -m app.importers.sheets_csv /path/to/sheets-csv"
